# 목표
- 에이전트는 LLM을 이용하여 추론(Reason), 행동(Act)을 교차 반복하여서 문제를 자율적으로 해결 -> 인공지능 패턴 : ReAct(Reasoning and Acting)
- 한번의 ReAct 호출을 넘어서 결과를 검증 -> 재시도 -> 루프 구조 구성
- 제한을 두고 반복 수행 진행(임시-> 비용/시간 절감) -> 처리가 않되면 Human in the loop를 같이 적용 할수 있다.
- 질문=>답변 (기존), 계획->실행->검증->부족하다고 평가-> 수정계획->실행... 작동하는 agent 구성
- 이렇게 에이전트를 작동시키는 방식을 루프 엔지니어링이라고 함
    - 사람이 매번 프롬프트를 입력하는 방식에서 벗어나, AI 에이전트가 목표와 완료 조건을 달성할 때까지 스스로 판단·실행·검증을 반복하는 시스템을 설계하는 패러다임
